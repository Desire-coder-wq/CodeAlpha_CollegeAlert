## TECHNICAL NOTES FOR RECORDING

1. **Two Test Accounts Needed:**
   - Student: john@stanford.edu / student123
   - Admin: sarah.admin@stanford.edu / admin123

2. **Pre-populate some test alerts** in Firebase before recording so the dashboard isn't empty

3. **Recording Tips:**
   - Use Android Studio's built-in screen recorder or scrcpy
   - Record at 1080p resolution
   - Use a clean emulator or physical device
   - Enable "Show taps" in Developer Options for visibility

4. **Firebase Setup Required:**
   - Firebase Authentication enabled
   - Firestore database with collections: users, events, broadcasts
   - Firebase Cloud Messaging for push notifications
